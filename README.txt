CALCULADORA 3D A1 — PWA PERMANENTE

Archivos:
- index.html
- manifest.webmanifest
- sw.js
- icons/

Para publicarla de forma permanente:
1. Sube TODOS los archivos manteniendo la estructura de carpetas a un hosting HTTPS.
2. Recomendado: GitHub Pages, Cloudflare Pages o Netlify.
3. Abre la URL publicada una vez en Safari.
4. En iPhone: Compartir > Agregar a pantalla de inicio.

La app guarda ajustes e historial con localStorage y puede funcionar offline después de la primera carga.
